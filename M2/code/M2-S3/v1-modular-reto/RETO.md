# Reto — encontrar el limite roto

Este es el mismo sistema modular. Compila y se ejecuta: la salida es identica.

1. Ejecutalo:            `sh run.sh`
2. Analizalo:            `sh ../../herramientas/analizar.sh .`
3. El verificador falla. Lee la violacion que reporta.

Preguntas:
- Que modulo se metio donde no debia?
- Por que el programa sigue funcionando igual si algo esta mal?
- Arreglalo sin cambiar la salida del programa. El verificador debe pasar.

en otro modulo de este mismo proyecto.
